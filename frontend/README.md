# VoteChain Frontend

This is the React + TypeScript frontend for the Blockchain-Based Voting System.

## Technologies

- React
- TypeScript
- Vite
- Ethers.js
- MetaMask
- Solidity Smart Contract

## Features

- Connect MetaMask wallet
- View election status
- View candidates
- Cast votes
- Prevent duplicate voting
- Admin controls
- Register voters
- Add candidates
- Start and end elections
- Display election results
- Display winner and tie results
